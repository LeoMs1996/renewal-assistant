# 费率上浮/下浮规则（NCD 无赔款优待系数）

## 系数表（合成）
| 出险情况 | NCD 系数 |
|---|---|
| 连续 4 年无出险 | 0.65 |
| 连续 3 年无出险 | 0.75 |
| 连续 2 年无出险 | 0.85 |
| 连续 1 年无出险 | 0.95 |
| 新保/无记录 | 1.00 |
| 上年出险 1 次 | 1.10 |
| 上年出险 2 次 | 1.25 |
| 上年出险 3 次及以上 | 1.50 |

## 计算公式
```
商业险保费 = Σ(各险种基准保费) × NCD 系数 × 用途系数 × 车龄系数(仅车损)
```

## 续保要点
- 出险一次可能导致次年保费上浮 10%~30%，小额案件（低于 2 倍保费）建议斟酌是否报案。
- 报价有效期 **24 小时**，NCD 以报价时刻核验结果为准。
