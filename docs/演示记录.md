# 演示记录 · 5 分钟脚本

> 对应交付：车险续保助手（SPEC v1.0.2） · 演示时间约 5 分钟 · 2026-11-12
> **所有报价均为模拟报价、数据均为合成数据**（页面与回复均有标注）。
> 准备：推荐在 **LLM 模式**下演示（`.env` 已配 GLM 凭证；早期 `use_nature='null'` 缺陷已修复，见 README §3）。若 `.env` 未配置则自动降级规则模式（回复带【规则模式】标注）——注意规则模式保额正则对「从100万升到200万」类双数字表述取首个数字，演示第 1 步建议照抄本文话术或直接用 LLM 模式。

## 0. 启动（30 秒）

```bash
cd renewal-assistant
.venv/bin/uvicorn server.app:app --host 127.0.0.1 --port 8000
# 另开终端验证：
curl -s http://127.0.0.1:8000/health
#   → {"status":"ok","llm_mode":"llm","graph":"langgraph","nodes":11,"wiki_entries":8}   # 未配 .env 时为 "rule"
```

浏览器打开 <http://127.0.0.1:8000/>，身份选 **OWN-1001 张伟**：右侧原保单卡显示 6 个险种与"距到期 23 天 · 临近到期"橙色高亮（**AC-01/02**，出参无身份证号/手机号）。

## 1. 选方案：续保比价（1.5 分钟）

左侧输入框发送（或 `curl -N`，见附录）：

> 我的车快到期了，帮我看看续保方案，三者险从 100 万升到 200 万

看点（SSE 事件依序推送，右栏轨迹抽屉同步回放）：
- 节点链：`intake→get_policy→parse_needs→retrieve_terms→quote→compare→await_confirm`（状态行脉动展示）；
- **报价卡**：quote_id / quote_version / valid_until（24h）/ 逐险种 line_items / 总保费，DSX 200万按 tiers 计价 1520×NCD0.85=**1292**（**AC-05/06**，保费由报价服务计算）；
- **保障差异表 + 价格对比**（先保障后价格）+ 条款依据 citations（带《虚构》条款名与 v2024.3 版本）；
- 出现 **await_confirm 待确认卡**，对话挂起（done=await_user）——先不点确认。

## 2. 改保额：重新询价 vs 复用报价（1 分钟）

同一会话继续发送：

> 预算控制在 2 万以内

→ **复用报价**：险种/保额未变，不重新询价（轨迹该轮 `query_quote` 调用次数 = 0，quote_id 不变），仅给出预算提示。

再发送：

> 三者险改到 300 万吧

→ **重新询价**：`parse_needs` 轨迹出现记忆撤回留痕
`invalidated:[{field:"sum_insured_changes", old:[…200万], new:[…300万], reason:"车主改口，旧偏好失效"}]`，
新报价卡 DSX=300万（1780×0.85=1513）。

## 3. 重启继续（1 分钟）

另开终端：

```bash
kill %1                     # 杀掉 uvicorn（或 Ctrl-C）
.venv/bin/uvicorn server.app:app --host 127.0.0.1 --port 8000   # 重启
```

回到浏览器（**同一会话**，不刷新身份）发送：

> 确认，按新方案投保

→ 会话挂起态 `awaiting_confirm` 从 `traces/sessions/` 恢复，直接出 **confirmed 订单卡（order_id）**；旧轨迹 `GET /trace/{trace_id}` 仍可回放（**AC-13/14 + 重启恢复**）。
（也可点待确认卡的「确认投保」按钮走 `POST /confirm`，重复点击返回同一 order_id——幂等。）

## 4. 收尾彩蛋（30 秒，可选）

- 条款问答（**AC-11**）：「车辆没年检出险赔吗」→ 命中 wiki-annual-inspection、答案带 citation、不进比价；
- 超范围（**AC-10，SPEC v1.0.1 裁决口径**）：「我要跑网约车」→ 不报价、提示转人工、引 wiki-ride-hailing；
- 越权演示：`curl -s -X POST .../confirm -d '{"quote_id":"QT-…","owner_id":"OWN-1002",…}'` → 422 OWNER_MISMATCH（硬失败）。
